# 模板目录样式与浏览

## Why

用户已批准改善目录可读性，同时提供多格式、完整分组筛选与可分享的 HTML 快照。

## What Changes

新增 BrowseRequest/BrowseResult、多选元数据筛选、跨语言关键词、分组排序、双重计数和共用 conformance 样例。

## Capabilities

### New Capabilities

- `catalog-browsing-presentation`: 统一查询驱动的样式、统计与报告。

### Modified Capabilities

旧发现参数和 JSON 字段保持兼容，默认人类列表升级为表格；detail 保留完整阅读路径。

## Impact

关联 promptrepo-catalog-browsing-v1 与 template-registry-catalog-presentation-v1。Eikona 本轮不改界面。
